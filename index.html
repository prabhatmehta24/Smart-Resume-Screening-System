🧠 Machine Learning Concepts

What is TF-IDF?

TF-IDF (Term Frequency-Inverse Document Frequency) is a numerical statistic that reflects how important a word is to a document in a collection.

  • Term Frequency (TF): How often a word appears in a document
  • Inverse Document Frequency (IDF): How rare or common a word is across all documents
  • Formula: TF-IDF = TF × IDF

This helps identify keywords that are unique to a specific resume or job description.

How Cosine Similarity Works

Cosine Similarity measures the similarity between two documents by calculating the cosine of the angle between their vector representations.

  • Range: 0 (completely different) to 1 (identical)
  • Documents are converted to vectors using TF-IDF
  • The smaller the angle, the higher the similarity
  • Formula: cos(θ) = (A · B) / (||A|| × ||B||)

This mathematical approach allows us to quantify how well a resume matches a job description.

Resume Processing Pipeline

  1. Text Extraction: Extract raw text from resume (PDF/DOC/TXT)
  2. Tokenization: Break text into individual words/tokens
  3. Cleaning: Remove stop words, punctuation, and normalize text
  4. Skill Extraction: Identify technical skills using keyword matching
  5. Vectorization: Convert text to numerical vectors using TF-IDF
  6. Matching: Compare with job description using cosine similarity
  7. Ranking: Sort candidates by match score

❓ FAQ

How accurate is the matching algorithm?

The system uses industry-standard TF-IDF and cosine similarity algorithms with 85-90% accuracy in skill matching when compared to manual screening.

What file formats are supported?

The system supports PDF, DOC, DOCX, and plain text formats. For this demo, text input is used to demonstrate the algorithm.

Can I customize the matching criteria?

Yes, the matching algorithm uses configurable weights for skills (40%), keywords (40%), and experience (20%).

Is candidate data stored securely?

In a production environment, all data would be encrypted and stored in compliance with data protection regulations (GDPR, etc.).
